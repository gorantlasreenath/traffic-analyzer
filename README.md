Smart Vehicle Counting System Using AI

An AI-powered computer vision and traffic video surveillance system designed to automate traffic monitoring. This project processes video feeds to detect, track, and accurately count different classes of vehicles in real time.

## 🚀 Key Features
* **Real-Time Detection:** Utilizes the state-of-the-art **YOLOv8** framework for fast and accurate vehicle detection.
* **Multi-Class Classification:** Correctly identifies and differentiates various types of vehicles (cars, trucks, motorbikes, buses).
* **Line-Crossing Counting:** Implements a virtual boundary tracking line to increment vehicle counts automatically without duplication.
* **Visual Dashboard:** Overlays real-time bounding boxes, tracking IDs, and class counters directly onto the video output window.

---

## 🛠️ Tech Stack & Tools
* **Language:** Python
* **Computer Vision Framework:** YOLOv8 (`ultralytics`)
* **Video & Image Processing:** OpenCV (`opencv-python`)
* **Version Control & Hosting:** Git & GitHub
